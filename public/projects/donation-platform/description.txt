Donation Platform
=================

Connect contributions with useful information.

A Laravel donation platform with Stripe payment integration and an AI chatbot connected to live donation statistics and event information.

Laravel · PHP · Stripe API · AI Chatbot · AlwaysData · Docker

Highlights

The problem
-----------
A donation experience combines a contribution flow with questions about campaigns, statistics, and events. This project connects payments and database-backed assistance rather than offering only a static campaign page.

Donation workflows / Payments / AI integration

Engineering considerations
--------------------------
Separate payment state from page state.
A successful-looking frontend is not proof of a completed payment. Provider-confirmed state, duplicate handling, and failure recovery are important payment-integration review points.
Ground assistance in current data.
The CV describes a chatbot connected to a live database. Donation totals and event answers should come from that data rather than generated guesses.
Handle contributions with care.
Payment errors, cancellation, and private donor information require clear boundaries. Security guarantees or audited compliance are not claimed in this project brief.

Technical focus
---------------
• Integrating payment services into a Laravel application.
• Connecting AI assistance with database-backed information.
• Combining contribution flows with campaign and event context.
Possible extensions
Possible extensions include documented payment-recovery tests, accessibility checks, and stronger donor privacy controls. No donation totals, impact statistics, or conversion results are claimed.
